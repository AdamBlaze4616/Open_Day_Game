## How to edit it from the GitHub website

1. Sign in to GitHub using your AdamBlaze4616 account.
2. Open the `Open_Day_Game` repository.
3. Open the `blazelink` folder.
4. Open `index.html`.
5. Press the pencil icon labelled **Edit this file**.
6. Find the text you want to change.
7. Make the change.
8. Press **Commit changes**.
9. Keep the branch as `main` for simple content changes.
10. Wait roughly 1–2 minutes, then refresh the live Blaze Link page.

## The easiest way to make changes

You do not need to edit the code yourself if you do not want to. Tell ChatGPT exactly what you want changed, for example:

- Add these three photos to Melbourne Companions.
- Rewrite my AskPAI section.
- Add a new certification.
- Change the orange to a darker red-orange.
- Add my resume as a button.
- Add a new LTUCS event.
- Add another research paper.
- Move my personal section to its own page.

ChatGPT can update the live repository for you.

## Important privacy rule

Do not place your private phone number or personal email directly into the public HTML. Keep them behind the planned contact approval system.
